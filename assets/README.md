# Gebouwillustraties

`city-atlas.png` is gemaakt met de ingebouwde ImageGen-tool, aansluitend bij het goedgekeurde ontwerp. Het transparante atlasbestand bevat vier kolommen en twee rijen. Het spel tekent elke cel afzonderlijk; de winkel gebruikt dezelfde illustraties. Geen externe afbeeldingen worden tijdens het spelen geladen.

Volgorde: woning, flat, park, politie; boerderij, akker, school, bloementuin.
